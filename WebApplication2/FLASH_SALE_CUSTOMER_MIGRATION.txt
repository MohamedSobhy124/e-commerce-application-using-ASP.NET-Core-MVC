========================================
FLASH SALE CUSTOMER SYSTEM - DATABASE MIGRATION
========================================

IMPORTANT: Run these commands in the Package Manager Console (PMC) in Visual Studio

Step 1: Navigate to the DataAccess project
-------------------------------------------
cd ../BulkyBook.DataAccess


Step 2: Create the Migration
-------------------------------------------
Add-Migration AddFlashSaleToCart


Step 3: Update the Database
-------------------------------------------
Update-Database


What This Migration Adds:
-------------------------------------------
Updates ShoppingCarts Table:
   - FlashSaleItemId (nullable, Foreign Key to FlashSaleItems)
   - FlashSalePrice (nullable, decimal(18,2))

This allows tracking of flash sale items in the shopping cart.


Verification:
-------------------------------------------
After running the migration, verify in SQL Server Management Studio that:
1. ShoppingCarts table has new FlashSaleItemId column
2. ShoppingCarts table has new FlashSalePrice column  
3. Foreign key relationship exists between ShoppingCarts and FlashSaleItems


Note:
-------------------------------------------
- Guest cart items are stored in session (no database migration needed)
- Flash sale data is tracked separately for authenticated and guest users
- Existing cart items won't be affected (nullable columns)


Troubleshooting:
-------------------------------------------
If migration fails:
- Make sure previous flash sale migration was run first
- Check if FlashSaleItems table exists
- Verify connection string is correct
- Make sure SQL Server is running
