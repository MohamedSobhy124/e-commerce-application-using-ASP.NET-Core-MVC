## 📝 How to Localize Any Page

### Example: Cart Page

**Current** (English hardcoded):
```cshtml
<h3>Shopping Cart</h3>
<button>Continue Shopping</button>
<p>Total Amount</p>
```

**Localized:**
```cshtml
<h3>@Localizer["ShoppingCart"]</h3>
<button>@Localizer["ContinueShopping"]</button>
<p>@Localizer["Total"]</p>
```

**Result:**
- Arabic: سلة التسوق، متابعة التسوق، المجموع الكلي
- English: Shopping Cart, Continue Shopping, Total

**That's it!** No injection needed - it's already global!
