===========================================
⚠️  IMPORTANT: RUN MIGRATION BEFORE USE!
===========================================

The application is currently running. You need to:

1. STOP the running application (close Visual Studio or stop debugging)

2. Run the migration using one of these methods:

   METHOD 1: Package Manager Console (Visual Studio)
   --------------------------------------------------
   Tools → NuGet Package Manager → Package Manager Console
   
   Then run:
   ```
   Add-Migration AddArabicFieldsAndImageToCategory -Project BulkyBook.DataAccess -StartupProject WebApplication2
   Update-Database -Project BulkyBook.DataAccess -StartupProject WebApplication2
   ```

   METHOD 2: .NET CLI (Terminal/PowerShell)
   -----------------------------------------
   Navigate to the solution directory, then run:
   ```
   cd BulkyBook.DataAccess
   dotnet ef migrations add AddArabicFieldsAndImageToCategory --startup-project ../WebApplication2
   dotnet ef database update --startup-project ../WebApplication2
   ```

===========================================
📋 WHAT THE MIGRATION WILL ADD:
===========================================

To the Categries table:
- NameAr (nvarchar(max), NOT NULL) - Arabic name
- DescriptionAr (nvarchar(max), NOT NULL) - Arabic description  
- ImageUrl (nvarchar(max), NOT NULL) - Image path

Note: Existing categories will need default values. The migration might fail if you have existing data. If so, you may need to:
1. Make fields nullable temporarily
2. Run migration
3. Update existing records
4. Make fields required again

===========================================
🎯 AFTER MIGRATION:
===========================================

1. Restart your application
2. Go to Admin → Categories → Create
3. You'll now see:
   - Name (English) field
   - الاسم (عربي) field  
   - Description (English) field
   - الوصف (عربي) field
   - Image upload field (required)
   - Image preview

4. For existing categories:
   - Go to Edit
   - Add Arabic translations
   - Upload images (optional - existing categories will work but should have images added)

===========================================
📁 IMAGE STORAGE:
===========================================

Images will be stored in:
- wwwroot/images/categories/
- Filenames: Guid-based to avoid conflicts
