====================================
CREATE DATABASE MIGRATION COMMANDS
====================================

OPTION 1: Using Package Manager Console (Visual Studio)
--------------------------------------------------------
1. Open Package Manager Console (Tools > NuGet Package Manager > Package Manager Console)

2. Make sure BulkyBook.DataAccess is selected in the dropdown

3. Run these commands:

Add-Migration AddNotifications -Project BulkyBook.DataAccess -StartupProject BulkyBook
Update-Database -Project BulkyBook.DataAccess -StartupProject BulkyBook


OPTION 2: Using .NET CLI (Command Line)
----------------------------------------
1. Open Terminal/PowerShell

2. Navigate to the DataAccess project folder:
cd "C:\Users\smoso\source\repos\e-commerce-application-using-ASP.NET-Core-MVC\BulkyBook.DataAccess"

3. Run these commands:

dotnet ef migrations add AddNotifications --startup-project ../WebApplication2
dotnet ef database update --startup-project ../WebApplication2


OPTION 3: Using Visual Studio Terminal
---------------------------------------
1. Open Terminal in Visual Studio (View > Terminal)

2. Make sure you're in the solution directory

3. Run:
cd BulkyBook.DataAccess
dotnet ef migrations add AddNotifications --startup-project ../WebApplication2
dotnet ef database update --startup-project ../WebApplication2


WHAT THIS DOES:
---------------
- Creates a new migration file for the Notifications table
- Updates your database with the new Notifications table
- Table includes: Id, Title, Message, Type, UserId, OrderId, IsRead, CreatedAt, Icon, Link


AFTER MIGRATION:
----------------
1. Restart your application
2. Clear browser cache (Ctrl+Shift+R)
3. Test by placing an order
4. Check if admins receive notifications


TROUBLESHOOTING:
----------------
If you get "Build failed" error:
- Make sure all projects compile without errors
- Rebuild solution (Build > Rebuild Solution)
- Try again

If migration already exists:
- Delete the migration file from Migrations folder
- Or use a different migration name: AddNotifications2
