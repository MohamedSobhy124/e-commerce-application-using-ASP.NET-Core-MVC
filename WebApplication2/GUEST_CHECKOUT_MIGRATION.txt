===========================================
DATABASE MIGRATION REQUIRED
===========================================

The OrderHeader model has been updated to support guest checkout.
You need to create and apply a new migration.

CHANGES MADE TO OrderHeader:
1. ApplicationUserId - Changed from 'string' to 'string?' (nullable)
2. Email - New field added (string?, nullable)
3. IsGuestOrder - New field added (bool, default: false)

TO CREATE THE MIGRATION:
------------------------

Open Package Manager Console and run:

1. Make sure you're in the WebApplication2 project directory
   
2. Run the following command:
   Add-Migration GuestCheckoutSupport -Project BulkyBook.DataAccess

3. After the migration is created, apply it:
   Update-Database -Project BulkyBook.DataAccess

ALTERNATIVE (using .NET CLI):
-----------------------------
1. Navigate to the solution directory in terminal

2. Run:
   dotnet ef migrations add GuestCheckoutSupport --project BulkyBook.DataAccess --startup-project WebApplication2

3. Apply the migration:
   dotnet ef database update --project BulkyBook.DataAccess --startup-project WebApplication2
