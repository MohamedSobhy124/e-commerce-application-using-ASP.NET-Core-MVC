========================================
FLASH SALE DATABASE MIGRATION
========================================

IMPORTANT: Run these commands in the Package Manager Console (PMC) in Visual Studio

Step 1: Navigate to the DataAccess project
-------------------------------------------
cd ../BulkyBook.DataAccess


Step 2: Create the Migration
-------------------------------------------
Add-Migration AddFlashSaleSystem


Step 3: Update the Database
-------------------------------------------
Update-Database


What This Migration Adds:
-------------------------------------------
1. FlashSales Table
   - Id (Primary Key)
   - Name (Flash Sale Name)
   - Description (Optional description)
   - StartDate (Start date and time)
   - EndDate (End date and time)
   - IsActive (Active status)
   - CreatedDate (Creation timestamp)

2. FlashSaleItems Table
   - Id (Primary Key)
   - FlashSaleId (Foreign Key to FlashSales)
   - ProductId (Foreign Key to Products)
   - FlashSaleQuantity (Quantity available for flash sale)
   - FlashSalePrice (Special flash sale price)
   - AddedDate (Date added to flash sale)


Verification:
-------------------------------------------
After running the migration, verify in SQL Server Management Studio that:
1. FlashSales table exists
2. FlashSaleItems table exists
3. Foreign keys are properly set up


Troubleshooting:
-------------------------------------------
If you get an error about existing tables:
- Check if tables already exist in the database
- If they do, you can skip the migration

If migration fails:
- Make sure you're in the BulkyBook.DataAccess directory
- Make sure the connection string in appsettings.json is correct
- Make sure SQL Server is running
