# 🚀 Quick Start: Get Your Site in Google (5 Steps)

## ⚡ Fast Track to Google Indexing

### Step 1: Go to Google Search Console NOW
👉 **https://search.google.com/search-console**

### Step 2: Add Your Website
1. Click "Add Property"
2. Enter: `https://idealweightnutrition.ae`
3. Choose verification method (HTML tag is easiest)

### Step 3: Add Verification Code
1. Google will give you a code like:
   ```html
   <meta name="google-site-verification" content="ABC123..." />
   ```
2. Add it to `_Layout.cshtml` in the `<head>` section (after line 16)
3. Deploy the change
4. Click "Verify" in Google Search Console

### Step 4: Submit Sitemap
1. In Search Console, click "Sitemaps" (left menu)
2. Enter: `sitemap.xml`
3. Click "Submit"

### Step 5: Request Indexing
1. Click "URL Inspection" (left menu)
2. Enter: `https://idealweightnutrition.ae/Customer/Home`
3. Click "Test Live URL"
4. Click "Request Indexing"

## ⏰ What Happens Next?

- **Day 1-2**: Google verifies your site
- **Day 3-7**: Google starts crawling
- **Week 2-4**: First pages appear in search results
- **Month 2+**: More pages indexed

## ✅ Check if You're Indexed

Search Google for:
```
site:idealweightnutrition.ae
```

If you see results, you're indexed! 🎉

## 🆘 Still Not Working?

1. **Check sitemap**: Visit `https://idealweightnutrition.ae/sitemap.xml`
2. **Check robots.txt**: Visit `https://idealweightnutrition.ae/robots.txt`
3. **Check for errors**: Look in Search Console → Coverage
4. **Be patient**: It takes 1-4 weeks minimum!
