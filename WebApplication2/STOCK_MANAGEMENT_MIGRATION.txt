# STOCK MANAGEMENT MIGRATION

## 📋 Run This Command

Open **Package Manager Console** in Visual Studio:
- Tools → NuGet Package Manager → Package Manager Console

Then run these commands:

```powershell
# Make sure you're in the DataAccess project
cd ../BulkyBook.DataAccess

# Create the migration
Add-Migration AddStockManagementToProduct

# Update the database
Update-Database
```

## OR Use .NET CLI (Terminal):

```bash
# Navigate to the DataAccess project
cd ../BulkyBook.DataAccess

# Create the migration
dotnet ef migrations add AddStockManagementToProduct --startup-project ../WebApplication2

# Update the database
dotnet ef database update --startup-project ../WebApplication2
```

## ✅ What This Adds to Products Table:

- **StockQuantity** (int) - Current stock level (default: 0)
- **MinimumStockAlert** (int) - When to show low stock warning (default: 5)

## 🎯 After Migration:

All existing products will have:
- StockQuantity = 0 (out of stock)
- MinimumStockAlert = 5

You can then update products with actual stock quantities from the admin panel.
