========================================
FLASH SALE ORDER TRACKING - DATABASE MIGRATION
========================================

IMPORTANT: Run these commands in the Package Manager Console (PMC) in Visual Studio

Step 1: Navigate to the DataAccess project
-------------------------------------------
cd ../BulkyBook.DataAccess


Step 2: Create the Migration
-------------------------------------------
Add-Migration AddFlashSaleToOrderDetail


Step 3: Update the Database
-------------------------------------------
Update-Database


What This Migration Adds:
-------------------------------------------
Updates OrderDetail Table:
   - FlashSaleItemId (nullable, Foreign Key to FlashSaleItems)

This allows tracking which order items came from flash sales
so we can deduct flash sale quantities after payment.


How It Works:
-------------------------------------------
1. Customer adds flash sale item to cart
   → ShoppingCart.FlashSaleItemId is set

2. Customer completes order
   → OrderDetail.FlashSaleItemId is copied from cart

3. Payment is successful
   → StockService deducts:
     a) FlashSaleItem.FlashSaleQuantity (flash sale stock)
     b) Product.StockQuantity (regular product stock)


Verification:
-------------------------------------------
After running the migration, verify in SQL Server Management Studio:

SELECT COLUMN_NAME 
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_NAME = 'orderDetails'
AND COLUMN_NAME = 'FlashSaleItemId';

-- Should return 1 row


Example Flow:
-------------------------------------------
Flash Sale Item: Whey Protein
- Product Stock: 100 units
- Flash Sale Quantity: 20 units
- Flash Sale Price: $49.99 (regular: $79.99)

Customer buys 2 units from flash sale:

After Payment:
- FlashSaleItem.FlashSaleQuantity: 20 → 18 ✅
- Product.StockQuantity: 100 → 98 ✅

If 18 more sold from flash sale:
- FlashSaleItem.FlashSaleQuantity: 18 → 0 ✅ (SOLD OUT)
- Product.StockQuantity: 98 → 80 ✅


Troubleshooting:
-------------------------------------------
If migration fails:
- Make sure previous flash sale migrations were run
- Verify FlashSaleItems table exists
- Check connection string is correct
- Make sure SQL Server is running
